# مبدل URL به قالب Elementor

یک برنامهٔ تحت وب کوچک که آدرس یک صفحهٔ عمومی را می‌گیرد، HTML آن را واکشی و تحلیل می‌کند،
و یک فایل `.json` تولید می‌کند که مستقیماً از مسیر زیر در وردپرس قابل درون‌ریزی است:

```
Elementor → Templates → Saved Templates → Import Templates
```

## ساختار پروژه

```
elementor-converter/
├── server.js                 # سرور Express + endpoint تبدیل
├── package.json
├── lib/
│   ├── elementorConverter.js # واکشی صفحه، پارس HTML، نگاشت به ویجت‌های Elementor
│   └── validateTemplate.js   # اعتبارسنجی ساختار خروجی با ajv
└── public/
    └── index.html            # فرانت‌اند: فیلد URL + دکمهٔ تبدیل/دانلود
```

## راه‌اندازی

```bash
cd elementor-converter
npm install
npm start
```

سپس مرورگر را روی `http://localhost:3000` باز کنید، آدرس صفحه را وارد کنید و روی «تبدیل» بزنید.
فایل JSON مستقیماً در مرورگر ساخته و دانلود می‌شود (نیازی به ذخیره روی سرور نیست).

> **توجه دربارهٔ تست:** این پروژه در محیطی بدون دسترسی به اینترنت نوشته شده، بنابراین
> `npm install` ممکن نبود. به‌جای آن، نسخهٔ سبکی از `cheerio`/`axios`/`ajv` فقط برای تست
> آفلاین ساخته شد و `convertUrlToElementorJson` + `validateTemplate` واقعاً روی یک
> صفحهٔ HTML فرضی (مشابه یک سایت کلینیک با منوی دسکتاپ/موبایل تکراری، hero، مقاله، فرم،
> ویدیوی یوتیوب و فوتر) اجرا شدند؛ فایل `sample-output.json` خروجی واقعیِ همین اجراست.
> همین تست یک باگ واقعی را هم آشکار کرد (پایین را ببینید: ویجت `form` قبلاً به‌اشتباه
> حذف می‌شد). پیش از استفادهٔ تولیدی، یک بار با `npm install` واقعی روی چند URL زنده هم
> اجرا و خروجی را در Elementor Pro import کنید.

## نحوهٔ کار برنامه

1. کاربر URL را در فرم وارد می‌کند و درخواست POST به `/api/convert` ارسال می‌شود.
2. سرور صفحه را با `axios` واکشی می‌کند (timeout ۱۵ ثانیه، حداکثر ۵ ریدایرکت).
3. HTML با `cheerio` پارس می‌شود.
4. بخش‌های اصلی صفحه شناسایی می‌شوند: ابتدا تگ‌های معنایی (`header`, `nav`, `section`,
   `article`, `footer`, `aside` — از جمله داخل `main`)؛ اگر صفحه از این تگ‌ها کم استفاده کرده
   باشد، فرزندان مستقیم `body` به‌عنوان بخش در نظر گرفته می‌شوند.
5. هر بخش به یک عنصر `container` (ساختار مدرن Elementor) تبدیل می‌شود و محتوای داخل آن
   به‌صورت بازگشتی پیمایش و به ویجت مناسب نگاشت می‌شود:

   | HTML | ویجت Elementor |
   |---|---|
   | `h1`–`h6` | `heading` |
   | `p` | `text-editor` |
   | `img` | `image` |
   | `a` (مستقل یا با کلاس btn/button) | `button` |
   | `video` | `video` |
   | `hr` | `divider` |
   | `ul` / `ol` | `icon-list` |
   | `form` | `form` |

6. خروجی نهایی مطابق schema رسمی Elementor ساخته می‌شود:
   `{ title, type: "page", version: "0.4", page_settings: [], content: [...] }`.
   هر عنصر یک `id` هگز ۸ کاراکتریِ یکتا (`crypto.randomBytes(4).toString("hex")`) و
   فیلد `elements` (حتی اگر خالی باشد) دارد.
7. ساختار با `ajv` در برابر یک schema بازگشتی اعتبارسنجی می‌شود (نوع فیلدها، یکتایی `id`ها،
   الزامی بودن `widgetType` برای ویجت‌ها). در صورت نامعتبر بودن، خطا به کاربر برگردانده
   می‌شود و فایلی تولید نمی‌شود.
8. فرانت‌اند فایل JSON معتبر را به‌صورت Blob می‌سازد و دکمهٔ «دانلود JSON» را نمایش می‌دهد.

## محدودیت‌های شناخته‌شده

- **بدون استایل اصلی سایت**: برنامه فقط ساختار و محتوا را استخراج می‌کند، نه CSS سایت مبدأ؛
  رنگ، فونت و چیدمان دقیق صفحهٔ اصلی بازسازی نمی‌شود (طبق خواستهٔ پروژه، فقط نگاشت ساختاری).
- **تصاویر**: به‌صورت لینک خارجی (`image.url`) نگه داشته می‌شوند؛ آپلود در کتابخانهٔ رسانهٔ
  وردپرس برعهدهٔ کاربر است.
- **فرم‌ها**: فیلدهای ورودی پایه (`input`, `textarea`, `select`) تشخیص داده می‌شوند، اما
  منطق سرور-ساید فرم (مثل ایمیل اکشن) بازسازی نمی‌شود.
- **صفحات پویا (SPA)**: چون صفحه فقط با یک درخواست HTTP ساده واکشی می‌شود، محتوایی که با
  جاوااسکریپت سمت کلاینت رندر می‌شود (مثل برخی اپ‌های React/Vue بدون SSR) دیده نمی‌شود.
- **عمق تودرتو**: برای جلوگیری از خروجی بیش‌ازحد بزرگ، حداکثر عمق پیمایش ۶ سطح و حداکثر
  ۴۰ بخش / ۳۰ ویجت در هر بخش در نظر گرفته شده (قابل تنظیم در `lib/elementorConverter.js`).
- **عناصر ناشناخته** (مثل `canvas`, `svg` مستقل، ویجت‌های سفارشی) نادیده گرفته می‌شوند و
  در آرایهٔ `warnings` که در پاسخ API برمی‌گردد گزارش می‌شوند.

## توسعهٔ بعدی پیشنهادی

- افزودن تشخیص ردیف/ستون (flex/grid) برای بازسازی چیدمان چندستونه به‌جای چینش عمودی ساده.
- استخراج رنگ پس‌زمینه/فونت از CSS محاسبه‌شده و نگاشت به `settings` کانتینر.
- پشتیبانی از حالت Legacy (`section` → `column` → `widget`) به‌عنوان یک گزینهٔ قابل‌انتخاب
  در فرانت‌اند، برای سازگاری با نسخه‌های قدیمی‌تر Elementor.
